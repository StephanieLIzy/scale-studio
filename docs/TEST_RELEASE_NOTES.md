# Scale Studio v0.1 公开测试说明

> 发布日期：2026-08-13

## 这次测试要验证什么

- 用户是否理解“真实尺寸验证”而不是“在线做设计”的产品定位。
- 授权码 + 昵称 + 独立成员 ID 的进入流程是否足够快。
- 用户能否顺利选择空间、上传物料、调整毫米尺寸并导出。
- 轮廓与实拍切换时，物料位置是否保持一致。
- 只读预览是否足够用于团队内部查看效果。
- 手机查看与电脑完整编辑的分工是否符合使用场景。

## v0.1 技术边界

这是公开可访问的交互测试版，用于验证产品、界面和完整任务路径；它还不是可承载正式客户数据的生产后台。

- 成员、授权计数、项目和管理数据目前保存在用户浏览器中。
- 跨设备恢复和只读分享使用 URL 内的加密安全性之外的“快照编码”，只适合测试，不应发送机密图片。
- 带大量或较大图片的项目可能超过浏览器可稳定处理的链接长度，此时应导出 PNG。
- 测试授权人数上限在单个浏览器内演示；全局并发 20 人限制需要后端数据库事务。
- 管理口令只是界面原型，不是正式认证。
- GitHub Pages 在中国大陆的连通和速度不提供 SLA。

正式用户版必须按架构文档补齐服务端身份、数据库事务、对象存储、服务端权限校验、撤销机制和审计日志后，再接收真实客户项目。
